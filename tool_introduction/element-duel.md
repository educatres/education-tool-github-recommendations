# 元素大對決

## 簡短描述

運用週期表位置判斷元素性質的卡牌對戰遊戲，練習原子量、原子半徑、電負度與游離能趨勢。

## 教育工作者摘要

元素大對決收錄 22 種主族元素與稀有氣體，可選擇挑戰電腦或兩人輪流對戰。每回合翻開兩張只標示原子序、元素分類與週期表位置的卡牌，輪到的玩家必須依週期趨勢選出自己較大的性質，選對便取得卡牌。系統會在每回合解釋左右、上下位置所代表的趨勢，也說明半滿軌域、原子量與稀有氣體半徑等經典例外；若兩個位置方向的影響相反，則標示僅靠位置無法判斷。它適合國中理化與高中化學的分組競賽、形成性評量或複習。

## 教學用途

- 在週期表單元中練習原子半徑、電負度與第一游離能的方向趨勢
- 分組對戰時要求學生先口頭說明判斷理由，再選擇比較項目
- 蒐集遊戲出現的例外案例，延伸討論電子組態與資料定義

## 導入注意

- 卡面刻意不列性質數值，活動重點是趨勢推理，不宜取代定量資料查詢
- 斜對角元素可能無法只靠週期表位置判斷，應把平手說明作為比較證據限制的教材
- 原子半徑採單鍵共價半徑等特定資料定義，和其他教科書或資料表可能略有差異
