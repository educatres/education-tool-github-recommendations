# 文具店開張囉

## 簡短描述

以文具店情境練習認識錢幣、湊出總價與找錢的國小數學遊戲，包含三種難度與分步提示。

## 教育工作者摘要

文具店開張囉讓學生扮演小老闆，依客人購買的文具從錢箱取出正確金額，或根據付款金額找零。簡單模式練習單價、重複加法與湊錢，進階模式依總價找錢，困難模式則先計算 2～3 項商品總額，再完成 100 或 500 元付款的找零。答錯後會提示尚差多少、拆解加總步驟，並比較減法與往上數兩種找錢策略；再次答錯才示範以較少張數完成的組合。工具支援注音、音效、觸控與離線使用，適合國小生活數學和補救教學。

## 教學用途

- 練習辨認面額、用不同錢幣組合湊出相同金額
- 在購物情境中運用重複加法、多項加總、減法與往上數找零
- 銜接教具錢幣或班級小商店活動，比較多種付款與找錢策略

## 導入注意

- 遊戲錢幣與鈔票是只保留面額和顏色的教學圖案，不是真實新臺幣樣式
- 商品價格為練習而設計，且部分難度會隨機變動，不代表實際市價
- 最佳成績只保存在目前瀏覽器，換裝置或清除網站資料後不會保留

可直接開啟 GitHub Pages 線上版本；離線使用時下載 index.html，以電腦或平板瀏覽器直接開啟即可。
