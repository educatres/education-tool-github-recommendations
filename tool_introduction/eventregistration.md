# 活動報名管理系統

## 簡短描述

用於建立活動報名與彙整參與資訊的線上工具，協助教師、行政人員或活動主辦者管理報名流程。

## 教育工作者摘要

活動報名管理系統是一個可透過瀏覽器使用的活動行政工具，適合用於班級活動、教師研習、工作坊、講座或校內專題成果發表等情境。主辦者可將報名網址提供給參與者，集中蒐集活動所需的參與資訊並作為後續名單整理與通知的依據。它的定位是降低小型活動的行政溝通成本，讓教師與承辦人員能把更多時間放在活動設計、現場引導與參與者支持上。

## 教學用途

- 建立班級活動、校內講座、工作坊或教師研習的報名入口
- 在活動前整理參與名單，協助準備座位、教材、器材或分組安排
- 作為專題發表、競賽或課外活動的報名資訊彙整工具

## 導入注意

- 報名欄位應以活動必需資訊為限，避免蒐集身分證字號、住址等非必要個資
- 對未成年學生蒐集資料時，應符合校內個資保護規範並清楚說明用途與保存期限
- 正式活動前建議先以測試資料走完報名、修改與名單整理流程

## 啟動或安裝方式

可直接開啟線上版本使用；若要自行部署或調整功能，請參閱 GitHub repository 的 README 與原始碼說明。
